# RISC-V-Processor-RTL-to-GDSII-Implementation
A RISC-V processor executes instructions by fetching them from memory, decoding them, performing the required operation in the ALU, accessing memory when needed, and writing the result back to registers. The RTL-to-GDSII implementation converts this processor design from Verilog RTL into a physical chip layout that can be fabricated.
